# Begriffe von A bis Z

| Begriff | Bedeutung |
| --- | --- |
| **Airmass (X)** | Wie viel Luft das Sternlicht durchquert, relativ zum Zenit (X = 1). Bei 30° Höhe etwa 2. Mehr Luft = mehr Abschwächung und Flackern. |
| **Apertur** | Kreis um den Stern, in dem seine Helligkeit gemessen wird. Der Ring außen herum misst den Himmelshintergrund. |
| **Baseline** | Messzeit vor und nach dem Transit, als Vergleich für „normale“ Helligkeit. |
| **β (Beta)** | Faktor für zeitlich korreliertes Rauschen. 1 = rein zufällig. Siehe [Lichtkurve verrauscht](#hilfe:rauschen). |
| **BJD_TDB** | Zeitangabe, bezogen auf den Schwerpunkt des Sonnensystems; gleicht aus, dass die Erde mal näher, mal weiter vom Stern ist (bis ±8 min). |
| **Ensemble** | Die Gruppe der Vergleichssterne, gegen die das Ziel gemessen wird. |
| **Ephemeride** | Vorhersage der Transitzeiten aus Referenzzeit T0 und Periode P. |
| **Flat, Bias, Dark** | Korrekturbilder: Vignettierung und Staub, Grundsignal der Kamera, Wärmesignal. |
| **Ingress, Egress** | Beginn und Ende des Transits (Planet tritt vor den Stern bzw. wieder heraus). |
| **Lauf** | Eine vollständige Auswertung einer Messung mit bestimmten Einstellungen. |
| **MCMC** | Zufallsverfahren, das viele mögliche Modelle durchprobiert und daraus die Fehlerbalken bestimmt. |
| **Meridian-Flip** | Umschlagen der Montierung, wenn der Stern den Meridian (Süden) passiert. |
| **O-C** | Beobachtet minus berechnet: Abweichung der gemessenen Transitmitte von der Vorhersage. |
| **OOT-RMS** | Streuung außerhalb des Transits (out of transit), in Promille. |
| **ppt, ‰** | Promille: 1 ppt = 0,1 % Helligkeitsänderung. |
| **Rp/R*** | Planetenradius geteilt durch Sternradius. Die Transittiefe ist etwa (Rp/R*)². |
| **RUWE** | Gaia-Kennzahl für die Güte der Position; über 1,4 oft ein Doppelstern. |
| **Sigma (σ)** | Standardabweichung, Maß für Streuung oder Fehler. „3 σ daneben“ ist auffällig. |
| **Sigma-Clipping** | Automatisches Entfernen von Punkten, die zu weit vom Modell liegen. Siehe [Ausreißer](#hilfe:ausreisser). |
| **Tc** | Gemessene Transitmitte. |
