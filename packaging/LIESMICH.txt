transit - Exoplaneten-Transits auswerten (portables Windows-Paket)
==================================================================

Dieses Paket enthaelt alles, was das Programm braucht, auch Python.
Es wird nichts installiert, Administratorrechte und Git sind nicht noetig.
Ein bereits installiertes Python auf dem PC wird nicht veraendert.

In 3 Schritten zur Oberflaeche
------------------------------
1. Vor dem Entpacken (empfohlen): Rechtsklick auf die ZIP-Datei > Eigenschaften >
   unten Haken bei "Zulassen" setzen > OK. Dann warnt Windows spaeter nicht bei
   jeder einzelnen Datei.

2. ZIP entpacken: Rechtsklick > "Alle extrahieren". Am besten in den Ordner, in dem
   die Messungen liegen, z. B.
       C:\Photometry\auto   ->   C:\Photometry\auto\exopipeline
   Die Oberflaeche findet Messungen im uebergeordneten Ordner (hier C:\Photometry\auto).

3. Im Ordner "exopipeline" doppelt auf  transit_gui.cmd  klicken.
   Ein schwarzes Fenster geht auf und der Browser zeigt die Oberflaeche
   (http://127.0.0.1:8765). Das schwarze Fenster offen lassen, solange man arbeitet;
   Schliessen beendet das Programm.
   Falls Windows "Der Computer wurde durch Windows geschuetzt" meldet:
   "Weitere Informationen" > "Trotzdem ausfuehren".

Optional: Doppelklick auf  Verknuepfung_anlegen.cmd  legt auf dem Desktop eine
Verknuepfung "Transit GUI" an.

Eigene Einstellungen
--------------------
Beim ersten Start wird  config.local.toml  angelegt (Kopie von config.example.toml).
Mit dem Editor oeffnen und anpassen:
  [site]      Standort (Breite, Laenge, Hoehe)
  [camera]    Gain, Ausleserauschen, Pixelgroesse, Brennweite
  [calib]     library = Ordner mit Master-Bias/Dark/Flat
  [paths]     astap = Pfad zu astap_cli.exe, archiv_wurzel = z. B. NAS-Ordner
  [observer]  eigener Name fuer das Ergebnisblatt
Einzelne Werte (z. B. Kalibrierung) lassen sich auch in der Oberflaeche unter "Erweitert" setzen.
Erklaerung aller Werte: HANDBUCH.md (auch im Browser unter http://127.0.0.1:8765/handbuch)
und die Hilfe in der Oberflaeche (Taste F1 oder "?").

Zusaetzlich noetig (nicht im Paket)
-----------------------------------
- ASTAP mit Sternkatalog (z. B. D50) fuer das Plate-Solving: https://www.hnsky.org/astap.htm
- optional AstroImageJ: https://www.astro.louisville.edu/software/astroimagej/
- Internet fuer Gaia-, ExoClock- und NASA-Abfragen (Ergebnisse werden in cache\ gemerkt)

Neue Version einspielen
-----------------------
Das neue ZIP einfach ueber den alten Ordner entpacken und "Dateien ersetzen" waehlen.
Eigene Einstellungen (config.local.toml), Logbuch und Cache bleiben erhalten,
weil sie nicht im Paket stecken.

Probleme?
---------
- Browser geht nicht auf: http://127.0.0.1:8765 selbst im Browser eingeben.
- Laeuft transit_gui.cmd schon, oeffnet ein zweiter Doppelklick nur den Browser.
- Schwarzes Fenster schliesst sich sofort: die Fehlermeldung bleibt stehen, bis eine
  Taste gedrueckt wird; den Text bei einer Rueckfrage mitschicken.

Kommandozeile (fuer Fortgeschrittene): PowerShell im Ordner oeffnen,  .\transit hilfe
